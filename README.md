## 🧪 Security Research & Vulnerability Testing Context

This clone was developed specifically to serve as a **controlled, sandboxed environment** for authorized security research, penetration testing, and vulnerability assessment practice. 

### Purpose of the Environment:
* **Defensive Coding:** To identify common web vulnerabilities (such as those outlined in the OWASP Top 10) within the codebase and implement secure patches (e.g., input sanitization, parameterized queries, and secure header configurations).
* **Safe Practice:** To simulate and understand security flaws locally without interacting with, disrupting, or targeting any live public or government infrastructure.

> 🔴 **STRICT WARNING:** This environment is strictly local. Testing tools, automated scanners, or manual payloads should **ONLY** be directed at your own locally hosted instance (e.g., `localhost`). Running security tools against the official government domain (`forestodisha.in` or any `.gov.in` subdomains) without explicit, legal written authorization is illegal under the Information Technology Act, 2000, and is strictly prohibited.
